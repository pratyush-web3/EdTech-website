# Accademia Aurea

Sito premium Next.js per una piattaforma italiana di formazione digitale.

## Avvio

```bash
npm install
npm run dev
```

Apri `http://localhost:3000`.

## Contatti centralizzati

Email, telefono, WhatsApp, sedi, P.IVA e riferimenti privacy sono in:

`lib/data/contact.ts`

Aggiornando quel file, le informazioni cambiano in footer, pagina contatti e documenti legali.

## Pagine incluse

Home, chi siamo, corsi, dettaglio corso, accademia, formazione, certificazioni, istruttori, blog, articolo, dashboard, contatti, FAQ, privacy e termini.

## Note tecniche

Il progetto usa Next.js 15, TypeScript strict, Tailwind CSS, GSAP, Framer Motion, lucide-react e tre temi selezionabili: Oro Veneziano, Rinascimento e Milano Notte.
